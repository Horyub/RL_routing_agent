An implementation of a simple environment to get used to work with Gymnasium. 
The core idea is to implement and agent that learn how to minimize the number of hops required to reach a destination from a source (both sampled randomly). 
The reward function was modeled on this idea, so the agent receives a reward of +1 when it finds the destination and a penalty of -0.05 when it does an hop but it doesn't reach the destination. A max_step variable is used to avoid infinite loops and, if the number of hops are equal to the number of max_steps, than the episode is stopped and the agent is assigned a penalty of -0.2
